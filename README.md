# rfshadow-update

Arquivos de atualização automática do RF Shadow.

Gerado pelo PatchMaker (`patch.ini` + um `.zip` por arquivo). O launcher lê o `patch.ini`, compara com o cliente
e baixa só o que mudou. **Não edite à mão** — para publicar, coloque os arquivos no `input` do PatchMaker,
rode o PatchMaker e faça commit/push aqui.
